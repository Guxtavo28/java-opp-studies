# Java OOP Studies



Repositório destinado aos meus estudos de Programação Orientada a Objetos utilizando Java.



O objetivo é registrar exercícios e implementações desenvolvidos durante o estudo dos principais conceitos de orientação a objetos.



## Conteúdos



- Classes e objetos

- Métodos

- Getters e Setters

- Encapsulamento

- Relacionamento entre classes

- Interfaces

- Herança

- Polimorfismo



## Objetivo



Este repositório faz parte da minha preparação para desenvolvimento backend com Java.



Os conceitos estudados aqui serão posteriormente aplicados em projetos práticos.
